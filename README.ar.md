# layoutfix

العربية · **[English](README.md)**

أداة تصحّح النص المكتوب بلغة لوحة مفاتيح خاطئة. اختصار واحد، والنص يتحول في مكانه.

```
hgsghl ugd;l     →   السلام عليكم
اثممخ            →   hello
```

تكتب بسرعة، ثم ترفع نظرك فتجد اللغة كانت خطأ. بدل أن تمسح السطر كله وتعيد
كتابته، اضغط **Ctrl+Alt+L**.

> أخت [translatefix](https://github.com/mosabah1/translatefix) التي تترجم النص
> المحدد بـ **Ctrl+Alt+T**. فُصلتا عمداً: هذه لا تتصل بالشبكة إطلاقاً، والترجمة
> مضطرة لإرسال نصك إلى طرف ثالث. شغّلهما معاً — لا تتعارض اختصاراتهما.

---

## التثبيت

1. نزّل `layoutfix.exe` من [آخر إصدار](../../releases/latest).
2. ضعه في أي مكان وانقر عليه مرتين.
3. تظهر أيقونة قرب الساعة. هذا كل شيء — بلا تنصيب وبلا Python.

ولتشتغل مع ويندوز تلقائياً: كلك يمين على الأيقونة ← **تشغيل مع ويندوز**.

### ويندوز سيحذّرك أول مرة

الملف غير موقّع رقمياً (الشهادة تكلف مئات الدولارات سنوياً)، فيظهر لك:

> **Windows protected your PC**

اضغط **More info** ثم **Run anyway**.

وقد تعترض بعض مكافحات الفيروسات أيضاً، وهذا متوقع لأداة كهذه — فهي ترسل ضغطات
مفاتيح وتقرأ الحافظة، وهذا سلوك keylogger حرفياً. الفرق في ما **لا** تفعله،
وتجده في [هل هي آمنة؟](#هل-هي-آمنة) أدناه. وإن كنت لا تثق بملف جاهز، الكود
أمامك و[بناؤه بنفسك](#البناء-من-المصدر) أمر واحد.

## الاستخدام

| الحالة | الضغطة |
|---|---|
| النص محدد | **Ctrl+Alt+L** — يحوّل المحدد |
| لا يوجد تحديد | **Ctrl+Alt+L** — يحوّل السطر من بدايته حتى المؤشر |
| كلمة إنجليزية فيها `gh` مثل light و right | **Ctrl+Alt+Shift+L** — انظر [الغموض الوحيد](#الغموض-الوحيد) |

الاتجاه يُكتشف تلقائياً: العربي يصير إنجليزياً والإنجليزي يصير عربياً. وبعد
التحويل تُبدَّل لغة الإدخال نفسها، فتكمل الكتابة من غير أن تفكر.

تعمل في أي برنامج يدعم Ctrl+C / Ctrl+V — المتصفح، Word، واتساب، تيليجرام،
VS Code.

## الإعدادات

كلك يمين على الأيقونة ← **فتح ملف الاعدادات**، أو عدّل مباشرة:

```
%APPDATA%\layoutfix\settings.ini
```

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `hotkey` | `ctrl+alt+l` | الاختصار الرئيسي |
| `hotkey_alt` | `ctrl+alt+shift+l` | نفسه لكن يفكك `لا` إلى `g`+`h` |
| `switch_layout` | `true` | بدّل لغة الإدخال بعد التحويل |
| `fallback_line` | `true` | حوّل السطر الحالي إذا لم يكن فيه تحديد |
| `notify` | `true` | اشرح سبب الفشل برسالة بدل صوت مبهم |
| `debug` | `false` | اكتب `layoutfix.log` بجانب ملف الإعدادات |

احفظ الملف ثم أعد تشغيل الأداة ليسري التغيير.

وإن بدا أن تعديلك بلا أثر، شغّل `layoutfix.exe --check`: يطبع ملف الإعدادات الذي
يقرأه، ويقول صراحةً إن تعذّرت قراءته. النسخة 1.0.0 كانت **تتجاهل بصمت** ملفاً
محفوظاً بـ UTF-8 مع BOM — وهو ما تكتبه عدة محررات على ويندوز افتراضياً — وتعود
للقيم الافتراضية بلا أي إشارة. أُصلح في 1.0.1.

**الوضع المحمول:** ضع `settings.ini` بجانب `layoutfix.exe` فيُستخدم بدلاً عنه،
وتصير الأداة صالحة للعمل من فلاش مع إعداداتها.

## هل هي آمنة؟

سؤال في محله لأداة تكتب نيابةً عنك. إليك ما تفعله فعلاً:

- **لا تراقب لوحة المفاتيح.** لا يوجد `WH_KEYBOARD_LL`، ولا مخزن لضغطاتك، ولا
  شيء يسجّل ما تكتبه. تسجّل اختصارَين عبر `RegisterHotKey` ثم تنام حتى تضغط أحدهما.
- **لا تقرأ النص إلا لحظة ضغطك الاختصار**، بإرسال Ctrl+C للنافذة النشطة — وهو
  النسخ نفسه الذي تفعله بيدك.
- **لا تكتب شيئاً على القرص** إلا إذا فعّلت `debug = true` بنفسك، وحينها في ملف
  سجل محلي تقرأه وتحذفه متى شئت.
- **لا تتصل بالإنترنت إطلاقاً.** لا فحص تحديثات ولا إحصاءات ولا أي شيء يُرسل.
- **تُعيد حافظتك** بعد كل تحويل، وحتى عند الفشل.

الأداة كلها ملف Python واحد مقروء، بلا أي مكتبة خارجية — المكتبة القياسية
وواجهة ويندوز فقط. تستطيع قراءته كاملاً في جلسة واحدة.

## الغموض الوحيد

`لا` تنتج من ضغطتين مختلفتين: مفتاح `b` (الذي يطبعها جاهزة)، وتتابع `g` ثم `h`
(ل + ا). الشكل على الشاشة واحد، فلا سبيل لمعرفة الأصل يقيناً.

الافتراضي يفضّل `b`، لأن حرف b أكثر شيوعاً في الإنجليزية بنحو عشرين ضعفاً من
تتابع `gh`. لذلك `مهلاف` تطلع `libt`. ولتلك الكلمات اضغط **Ctrl+Alt+Shift+L**
فتحصل على `light`.

هذا ليس خللاً، ولا يمكن حلّه بغير قاموس.

## إذا لم يتغير النص

الأداة تشرح سبب الفشل برسالة تسمّي البرنامج الذي كانت تعمل عليه:

| الرسالة | المعنى |
|---|---|
| لم أتمكن من قراءة النص | البرنامج لم يستجب لـ Ctrl+C، أو يعمل بصلاحيات مسؤول |
| لا شيء للتحويل | قُرئ النص لكن التحويل لا يغيّره (أرقام، رموز) |
| الحافظة مشغولة | برنامج آخر يمسك الحافظة |

ولتفصيل أدق، اجعل `debug = true` في الإعدادات وأعد التشغيل. السجل يُكتب بجانب
ملف الإعدادات ويسجّل: اسم البرنامج، وعدد الحروف المنسوخة، وهل حجب ويندوز الإرسال.

**إذا كان البرنامج الهدف يعمل بصلاحيات مسؤول (Administrator) والأداة لا**، فإن
ويندوز يحجب كل إرسال إليه (UIPI) — شغّل الأداة بصلاحيات مسؤول أيضاً.

### إذا توقفت الأداة وحدها

تحقق هل العملية تعمل، ومن هو أبوها:

```bash
powershell -NoProfile -Command "Get-CimInstance Win32_Process -Filter \"Name='layoutfix.exe'\" | Select-Object ProcessId, ParentProcessId"
```

إن شُغّلت الأداة من داخل طرفية أو أداة آلية، تصبح تابعة لشجرة عملياتها، وبعض
البيئات تقتل المجموعة كاملة عند الخروج — فتموت الأداة بلا أثر في سجل الانهيارات.

## البناء من المصدر

تحتاج Python 3.9 أو أحدث على ويندوز. لا مكتبات خارجية للتشغيل؛ PyInstaller
و Pillow فقط لبناء الملف التنفيذي وأيقونته.

```bat
pip install pyinstaller pillow
build.cmd
```

والناتج `dist\layoutfix.exe`. أو شغّلها من المصدر مباشرة:

```bat
pythonw layoutfix.py
```

### الاختبارات

```bat
python layoutfix.py --selftest      ; جدول التخطيط بالاتجاهين
python test_clipboard_race.py       ; التقاط النص المحدد
python test_settings.py             ; ملف الإعدادات، مع BOM وبدونه
python layoutfix.py --check         ; الاختصار والأيقونة والحافظة وبنى Win32
```

`test_clipboard_race.py` يغطي أصعب جزء في الأداة: التقاط النص المحدد. ثلاثة
أخطاء حقيقية وقعت هناك، وكلها مغطاة باختبارات تراجع الآن:

1. **المفاتيح ما زالت مضغوطة.** الاختصار يُطلق وأصابعك على `Ctrl+Alt`، فيصل
   البرنامج `Ctrl+Alt+C`. وإرسال `keyup` صناعي لا يغيّر حالة المفتاح الفيزيائي —
   لا بد من انتظار رفعها فعلياً عبر `GetAsyncKeyState`.
2. **scan code صفر.** Chrome وتطبيقات Electron تتجاهل الأحداث التي تصل بلا
   scan code، فنملؤه من `MapVirtualKeyW` ونضيف `KEYEVENTF_EXTENDEDKEY` لـ
   `Home`/`End`.
3. **`GetClipboardSequenceNumber` وحده لا يكفي.** يرتفع عند `EmptyClipboard`
   أي **قبل** أن يكتب البرنامج النص، فتقرأ حافظة فارغة وتستسلم. والأسوأ أنك قد
   تقرأ محتوى حافظة المستخدم **السابق** فتحسبه النص المحدد. كتابة علامة فريدة
   قبل Ctrl+C تزيل الخطأين: إن بقيت العلامة فلا شيء نُسخ، ويستحيل عودة محتوى
   قديم لأنه مُحي أصلاً.

## خريطة التحويل

مبنية على تخطيط **Arabic 101** القياسي في ويندوز مقابل **US QWERTY**. تغطي
الحروف، والتشكيل مع Shift، والترقيم العربي (`،` `؛` `؟`)، والأقواس المعكوسة،
والأرقام العربية الهندية (`٠١٢٣` → `0123`).

إضافة تخطيط آخر مسألة إضافة جدول مثل `EN_TO_AR` غالباً؛ المساهمات مرحب بها.
